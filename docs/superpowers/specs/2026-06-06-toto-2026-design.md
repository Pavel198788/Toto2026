# Тото 2026 — Дизайн-спек

**Дата:** 2026-06-06  
**Проект:** Футбольный тотализатор Чемпионата мира 2026

---

## Обзор

Веб-сайт для группы друзей: каждый участник делает прогнозы счётов матчей ЧМ 2026, очки начисляются автоматически, ведётся общая таблица рейтинга. Правила основаны на регламенте тотализатора Евро 2024.

## Модели данных (Prisma)

```prisma
model User {
  id              String            @id @default(cuid())
  name            String
  email           String            @unique
  password        String            // bcrypt hash
  isAdmin         Boolean           @default(false)
  predictions     Prediction[]
  bonusPredictions BonusPrediction[]
  createdAt       DateTime          @default(now())
}

model Match {
  id          String       @id @default(cuid())
  externalId  Int          @unique  // ID из football-data.org
  homeTeam    String
  awayTeam    String
  stage       Stage
  group       String?      // "A"–"L", только групповой этап
  kickoff     DateTime
  homeScore   Int?         // null = матч не сыгран
  awayScore   Int?
  winner      String?      // команда-победитель (для пенальти)
  status      MatchStatus  @default(SCHEDULED)
  predictions Prediction[]
  updatedAt   DateTime     @updatedAt
}

model Prediction {
  id        String   @id @default(cuid())
  userId    String
  matchId   String
  homeScore Int
  awayScore Int
  winner    String?  // победитель по пенальти (плей-офф)
  points    Int?     // null = матч ещё не сыгран
  createdAt DateTime @default(now())
  user      User     @relation(fields: [userId], references: [id])
  match     Match    @relation(fields: [matchId], references: [id])
  @@unique([userId, matchId])
}

model BonusPrediction {
  id     String    @id @default(cuid())
  userId String
  type   BonusType // SEMIFINAL | FINALIST | CHAMPION
  team   String
  points Int?
  user   User      @relation(fields: [userId], references: [id])
}

enum Stage {
  GROUP
  R16
  QUARTERFINAL
  SEMIFINAL
  THIRD_PLACE
  FINAL
}

enum MatchStatus {
  SCHEDULED
  IN_PLAY
  PAUSED
  FINISHED
  POSTPONED
}

enum BonusType {
  SEMIFINAL
  FINALIST
  CHAMPION
}
```

## Правила начисления очков

Источник: регламент тотализатора Евро 2024, адаптирован для ЧМ 2026.

### Групповой этап

| Ситуация | Очки |
|----------|------|
| Точный счёт (100%) | **11** |
| Верный исход | **10 − N** (N = кол-во неверно угаданных голов) |
| Неверный исход | **0** |
| Нет прогноза | **0** |

Пример: прогноз 2:1, результат 3:0 → верный исход (победа), погрешность по голам = 2 → 10 − 1 − 1 = **8 очков**

### Плей-офф (1/8, 1/4, 1/2, матч за 3-е место)

| Ситуация | Очки |
|----------|------|
| Точный счёт + верный победитель (100%) | **22** |
| Верный исход осн./доп. времени | **10 − N** |
| Верный победитель (в т.ч. по пенальти) | **+10** |
| Неверный исход и победитель | **0** |

### Финал

| Ситуация | Очки |
|----------|------|
| Точный счёт + верный победитель (100%) | **32** |
| Верный исход осн./доп. времени | **15 − N** |
| Верный победитель | **+15** |

### Премиальные прогнозы (подаются до старта турнира)

| Прогноз | Очки |
|---------|------|
| Каждый правильный полуфиналист | **+8** |
| Каждый правильный финалист | **+15** |
| Правильный чемпион | **+30** |

### Определение победителей тотализатора

Призовой фонд делится между топ-3 в соотношении **5:3:2**.

При равенстве очков: больше 100%-ных прогнозов → больше очков без премиальных → делят поровну.

## Автосинхронизация матчей

**API:** [football-data.org](https://www.football-data.org/) v4 — бесплатный тариф, 10 req/min.

**Vercel Cron Jobs:**
- `*/2 * * * *` — каждые 2 минуты в дни матчей: синхронизируем текущие счета
- `0 3 * * *` — ежедневно в 03:00 UTC: обновляем расписание

**Логика синхронизации** (`/api/cron/sync-scores`):
1. Запрашиваем матчи текущего дня у football-data.org
2. Для каждого завершённого матча сравниваем счёт с БД
3. Если счёт изменился — обновляем `Match`, статус → `FINISHED`
4. Запускаем `recalculatePoints(matchId)` — пересчитываем очки всех `Prediction` по этому матчу
5. Также обновляем `BonusPrediction.points` если вышел этап плей-офф

## Администраторская панель

Только для пользователей с `isAdmin = true`. Возможности:
- Просмотр списка участников
- Добавление / удаление участников
- Общая статистика турнира
- Ручной триггер синхронизации (кнопка "Обновить данные")

Ручной ввод результатов **не нужен** — всё берётся из API.

## Сводная таблица прогнозов (`/grid`)

Горизонтально-прокручиваемая таблица в стиле скриншота:

```
УЧАСТНИК    | ИТОГ  | ГР.  | ПРИЗ. | [Матч 1]   | [Матч 2]   | ...
            |       |      |       | Результат  | Результат  |
            |       |      |       | (жёлтый)   | (жёлтый)   |
------------|-------|------|-------|------------|------------|----
Иванов И.   | 1234  | +400 | +200  | 2:1 / +11  | 0:1 / +8   | ...
Петров П.   | 987   | +320 | +140  | 1:1 / 0    | 0:1 / +11  | ...
```

**Поведение:**
- Матчи сгруппированы по турам / стадиям (1 ТУР, 2 ТУР, …, 1/8 финала, …)
- В шапке каждого столбца — пара команд + фактический счёт (после завершения матча)
- В ячейке — прогноз участника + начисленные очки (зелёные = положительные, красные = отрицательные)
- До окончания матча прогнозы других участников **скрыты** (виден только свой)
- После окончания матча все прогнозы открываются

---

## Неизменяемость прогнозов

**Прогноз нельзя изменить после сохранения.**

- `POST /api/predictions` создаёт запись; повторный `POST` на тот же `matchId` возвращает `409 Conflict`
- На фронте кнопка "Сохранить прогноз" заменяется на "Прогноз сдан ✓" после первого сохранения
- Перед сохранением показывается диалог подтверждения: "Вы уверены? Изменить прогноз будет невозможно."
- Прогнозы принимаются только пока `Match.status === SCHEDULED` (до стартового свистка)

---

## Безопасность

- Пароли хранятся как bcrypt-хэши
- Прогнозы принимаются только при `Match.status === SCHEDULED`
- Повторная подача прогноза на тот же матч запрещена на уровне API (`@@unique([userId, matchId])`)
- API-роуты защищены проверкой сессии NextAuth
- `/admin` доступен только при `isAdmin = true`
- Vercel Cron защищён секретным заголовком `CRON_SECRET`
- Прогнозы других участников скрыты до окончания матча (не возвращаются API до `FINISHED`)
