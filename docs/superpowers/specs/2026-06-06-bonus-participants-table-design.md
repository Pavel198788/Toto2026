# Спецификация: таблица бонусных прогнозов участников

**Дата:** 2026-06-06  
**Статус:** Согласовано

## Контекст

Страница `/bonus` позволяет каждому участнику сделать бонусные прогнозы (полуфиналисты, финалисты, чемпион) до начала ЧМ (11 июня 2026). После начала ЧМ (`locked === true`) прогнозы закрываются. Нужно показать всем участникам, кто что поставил — сводная таблица всех прогнозов.

## Что нужно реализовать

### 1. API endpoint `GET /api/bonus/all`

**Путь:** `app/api/bonus/all/route.ts`

**Авторизация:** требует активной сессии (`auth()`). Если нет сессии — 401.

**Блокировка:** если `locked === false` (ЧМ ещё не начался) — возвращает 403 `{ error: "Данные скрыты до начала ЧМ" }`. Цель: участники не видят чужие прогнозы до старта.

**Логика `locked`:** совпадает с `/api/bonus/route.ts` — `locked = new Date() >= firstMatch.kickoff`.

**Ответ (200):**
```ts
{
  locked: boolean,       // всегда true (иначе 403)
  users: Array<{
    id: string,
    name: string,
    predictions: Array<{
      type: "SEMIFINAL" | "FINALIST" | "CHAMPION",
      team: string,
      points: number | null,
    }>
  }>
}
```

**Пользователи:** только `isAdmin === false`. Отсортированы по `name` (алфавит).

**Если у пользователя нет ни одного прогноза:** он всё равно включается в список с `predictions: []`.

### 2. Секция «Прогнозы участников» в `app/bonus/page.tsx`

**Видимость:** рендерится только когда `locked === true` (данные доступны только после начала ЧМ).

**Расположение:** после всего существующего контента страницы (ниже блока с ошибкой и подсказки про дату).

**Данные:** отдельный fetch к `/api/bonus/all` при монтировании, только если `locked === true`. Не блокирует загрузку основного контента — если `/api/bonus/all` не загрузилась, основная страница работает нормально.

#### Структура таблицы

| Участник | 🏅 Полуфиналисты (+8) | 🥈 Финалисты (+15) | 🏆 Чемпион (+30) | Очки |
|---|---|---|---|---|
| Паша | 🇧🇷 🇦🇷 🇫🇷 🇩🇪 | 🇧🇷 🇦🇷 | 🇧🇷 Brazil | +46 |
| Аня | 🇪🇸 🇫🇷 🇵🇹 🇳🇱 | 🇪🇸 🇫🇷 | 🇪🇸 Spain | — |
| Миша (не заполнил) | не заполнил | — | — | — |

**Правила отображения:**

- **Флаги:** `teamFlag(team)` из `lib/flags.ts` перед каждым названием команды
- **Полуфиналисты:** 4 флага+названия через пробел (или «не заполнил» если predictions пуст)
- **Финалисты:** 2 флага+названия или «—» если пуст
- **Чемпион:** 1 флаг+название или «—» если пуст
- **Очки:** сумма всех `prediction.points` для пользователя. Если все `points === null` → «—». Если есть начисленные → «+N»
- **Участник без прогноза:** строка полупрозрачная (`opacity-50`), в колонке полуфиналистов — «не заполнил»
- **Текущий пользователь:** строка слегка подсвечена (например `bg-yellow-900/20`)

#### Мобильная адаптация
Таблица обёрнута в `overflow-x-auto` — на узких экранах прокручивается горизонтально.

#### Подпись под таблицей
```
Очки начисляются по мере прохождения этапов. «—» — результат ещё не известен.
```

## Что НЕ нужно реализовывать

- Сортировку по очкам в таблице (просто алфавит)
- Пагинацию
- Какие-либо изменения схемы БД
- Новые Prisma-модели

## Граничные случаи

| Ситуация | Поведение |
|---|---|
| `locked === false` | `/api/bonus/all` возвращает 403; таблица не рендерится |
| Нет ни одного участника | Таблица не показывается (или пустое состояние «Пока нет участников») |
| `/api/bonus/all` вернул ошибку | Тихий fail, таблица не показывается |
| Очки ещё не начислены (все null) | «—» в колонке Очки |
