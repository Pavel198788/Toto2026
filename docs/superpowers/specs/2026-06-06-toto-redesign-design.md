# Дизайн: Редизайн Тото 2026

**Дата:** 2026-06-06  
**Статус:** Утверждён

## Цель

Переработать визуальный стиль сайта toto-2026.vercel.app — сделать все страницы единообразными, красивыми и читаемыми на мобильном устройстве. Стиль — спортивный, энергичный, с золотым акцентом.

## Дизайн-система

### Палитра

| Роль | Цвет | Hex |
|------|------|-----|
| Акцент (золото) | ![gold](https://via.placeholder.com/12/f5c842/f5c842.png) | `#f5c842` |
| Фон страницы | почти чёрный | `#0a0a0a` |

### Типографика

- **Заголовки страниц** — ЗАГЛАВНЫМИ, `font-weight: 900`, `letter-spacing: 2-4px`, цвет золото `#f5c842`
- **Лейблы полей/секций** — мелкие заглавные, `font-size: 9-10px`, `letter-spacing: 2px`, цвет золото
- **Подзаголовки / описания** — строчные, `font-size: 12-13px`, цвет `#555`
- **Данные (счёт, очки)** — `font-weight: 900`, крупные
- **Кнопка основная** — ЗАГЛАВНЫМИ с `letter-spacing: 2px` и `→`

### Компоненты

**Карточка:**
- `background: #111`, `border: 1px solid #1a1500`, `border-radius: 2-3px`
- Активная / выделенная: `border-left: 2px solid #f5c842`
- Верхняя граница формы: `border-top: 2px solid #f5c842`

**Кнопка главная:**
- `background: #f5c842`, `color: #000`, `font-weight: 900`
- Текст: ПОГНАЛИ → / ВОЙТИ / СОХРАНИТЬ и т.д.

**Кнопка вторичная:**
- `border: 1px solid #1a1500`, `color: #f5c842`, прозрачный фон

**Бейдж/статус:**
- `background: #1a1500`, `color: #f5c842`, мелкий текст с `letter-spacing`

## Навигация

### Структура
- Верхняя строка: лого `⚽ ТОТО 2026` слева (золото, жирный), имя пользователя справа (мелкий, серый)
- Нижняя строка: вкладки — МАТЧИ / РЕЙТИНГ / ПРОФИЛЬ / ГРУППЫ / СЕТКА / БОНУС / ПРАВИЛА
- Активная вкладка: `color: #f5c842`, `border-bottom: 2px solid #f5c842`
- Неактивные: `color: #333`
- Разделитель: `border-bottom: 2px solid #1a1500`

### Мобильный (< 640px)
- Верхняя строка фиксирована, не скроллится
- Строка вкладок: `overflow-x: auto`, `white-space: nowrap`, без горизонтального скролла страницы (`overflow-x: hidden` на `body`)
- Правый край вкладок: градиент-затухание `linear-gradient(to right, transparent, #0a0a0a)` — намёк что есть ещё
- Скрыть полосу прокрутки: `scrollbar-width: none` / `::-webkit-scrollbar { display: none }`

### Логин (`/auth/login`)
Аналогично регистрации. Заголовок: **С ВОЗВРАЩЕНИЕМ!**  
Кнопка: **ВОЙТИ →**

### Стартовая (`/`)

**Незалогинен:**
- Заголовок: **ТОТО 2026** (золото, крупный)
- Подзаголовок: серый, мелкий
- Кнопки: ВОЙТИ (золотая) / РЕГИСТРАЦИЯ (контур)
- Ближайшие матчи в карточках

**Залогинен:**
- Заголовок: **БЛИЖАЙШИЕ МАТЧИ** (золото, caps)
- Карточки матчей с золотым left-border у ближайшего

### Матчи (`/matches`)
- Заголовок секции: **РАСПИСАНИЕ МАТЧЕЙ**
- Вкладки туров и этапов — скролл на мобиле
- Карточка матча: команды по бокам, счёт по центру (золото если сыгран)
- Мой прогноз: мелкий зелёный текст под матчем
- Кнопка «Прогноз»: мелкий бейдж с `ПРОГНОЗ →`
- Даты группируются: **ПЯТНИЦА, 11 ИЮНЯ** (серый caps, `letter-spacing`)

### Рейтинг (`/leaderboard`)
- Заголовок: **РЕЙТИНГ УЧАСТНИКОВ**
- Строка лидера: `background: #1a1500`, `border-left: 2px solid #f5c842`
- Строка «Ты»: `background: #111`, золотой цвет, жирный
- Остальные: `background: #0d0d0d`, серые
- Полоска прогресса: тонкая (3px), золотая у лидера, серая у остальных

### Профиль (`/profile`)
- Аватар: квадратный (border-radius: 2px), золотой фон, буква имени
- Плашки статистики: 2×2 сетка, крупные числа (gold / green / orange)
- Заголовок секции прогнозов: **МОИ ПРОГНОЗЫ**
- Карточка прогноза: gold left-border если угадал, без border-left если нет

### Бонус (`/bonus`)
- Заголовок: **БОНУСНЫЕ ПРОГНОЗЫ**
- Бейдж «ДО 11 ИЮНЯ» / «ПРИЁМ ЗАКРЫТ»: мелкий, `background: #1a1500`
- Секции (полуфиналисты / финалисты / чемпион): карточки с gold top-border
- Выбранная команда: `background: #f5c842`, `color: #000`, жирный

### Группы, Сетка, Правила
Единый стиль: заголовок золотом капсом, карточки `#111 / #1a1500`, разделители `#1a1500`.

## Анимации

Минималистичные, не раздражающие:
- Кнопки: `transition: opacity 150ms` (hover → `opacity: 0.85`)
- Вкладки навигации: `transition: color 150ms, border-color 150ms`
- Карточки матчей: `transition: border-color 150ms` (hover → `border-color: #f5c842`)
- Живой матч: `animate-pulse` на индикаторе

## Что НЕ меняется

- Вся бизнес-логика (прогнозы, подсчёт очков, бонусы)
- API-маршруты
- Схема БД
- Тесты
