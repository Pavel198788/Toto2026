## Секция 1 — "ГОНКА: ПОСЛЕДНИЕ 5 МАТЧЕЙ"

**Что:** горизонтальный скролл карточек, отсортированный по дельте очков за последние 5 сыгранных матчей (от большего к меньшему).

**Логика:**
- Берём последние 5 матчей по дате (из `FINISHED`)
- Для каждого участника суммируем `points` по этим 5 матчам → `delta`
- Сортируем по `delta` убыванием

**Карточка (каждый участник):**
```
┌─────────────────────────┐
│ ↑ #1  Иванов            │  ← текущее место в общем рейтинге
│                         │
│   +36                   │  ← крупный шрифт, цвет по delta
│   ████████████░░░░░     │  ← бар: delta / max_delta * 100%
│   очков за 5 матчей     │
│                    🔥   │  ← только у топ-1
└─────────────────────────┘
```

**Цвета карточек:**
- 1-е место по дельте: зелёная рамка + `border-green-500/50` + `bg-green-900/10`
- 2-3 место: `border-[#1a1500]` обычный
- Последнее место: `border-red-900/30` + `bg-red-900/5`

## Секция 2 — "ДИНАМИКА ГОНКИ" (SVG-график)

**Что:** линейный SVG-график накопленных очков по матчам. X = матч №1..N, Y = сумма очков.

**Данные:**
- Строим для каждого участника массив `[matchIndex, cumulativePoints]`
- Матчи индексируются по порядку `kickoff`

**Визуал:**
- Лидер (максимум на последнем матче): жёлтая линия, `strokeWidth=2.5`, под линией градиентная заливка (`fill` с opacity 0.15)
- Топ-3: цветные яркие линии (зелёная, синяя, оранжевая), `strokeWidth=1.5`
- Остальные: `#374151` серые, `strokeWidth=1`, opacity 0.5
- Имена подписаны справа у конца каждой линии (только топ-5, остальные без подписи)
- Вертикальные пунктирные разделители между турами: `stroke-dasharray="2 4"`, цвет `#2a2000`
- Подписи туров: "ТУР 1", "ТУР 2", "ТУР 3" снизу

**Hover (client-only):**
- При наведении на область матча — вертикальная линия + tooltip с именами и очками топ-5

**Размер:** `width=100%`, `height=200px`, горизонтальный скролл при переполнении на мобиле.

## Секция 3 — "ГОРЯЧАЯ РУКА 🔥"

**Что:** топ-3 участника по текущей серии угаданных исходов подряд.

**Логика серии:**
- "Угаданный исход" = `points > 0` (победитель угадан, неважно точный счёт или нет)
- Считаем с конца (от последнего сыгранного матча), пока не встретим `points === 0` или матч без прогноза
- Серия = количество матчей подряд от конца

**Статус-метка в зависимости от длины:**
- 7+: `ОГОНЬ 🔥🔥🔥`
- 5-6: `В УДАРЕ 🔥🔥`
- 3-4: `В УДАРЕ ⚡`
- 1-2: `Неплохо 👍`
- 0: не показываем (или "все остыли" если у всех 0)

**Бар:** ширина = `streak / maxStreak * 100%`, цвет — градиент от жёлтого к зелёному.

**Если все серии = 0:** показываем карточку "Все остыли — ждём следующих матчей".

## Секция 4 — "САМЫЙ СМЕЛЫЙ 🎯"

**Что:** рейтинг участников по числу угаданных прогнозов, поставленных **против большинства**.

**Логика:**
- "Против большинства" = участник выбрал исход (П1/X/П2), за который проголосовало `≤ 40%` всех участников по этому матчу
- "Угадал" = `points > 0`
- Для каждого участника: `contrarian_wins` = кол-во таких попаданий, `contrarian_attempts` = всего попыток против большинства
- Сортировка по `contrarian_wins` убыванием, при равенстве — по проценту `wins/attempts`

**Строка каждого участника:**
```
┌─────┐
│  И  │  Иванов    5 попаданий из 8  →  62%
└─────┘  ████████████████░░░░░░░░░░░
```
- Кружок с инициалом, цвет — одна из 14 предопределённых тёмных палитр по индексу
- Бар: `contrarian_wins / max_contrarian_wins * 100%`, цвет жёлтый `bg-yellow-500`

**Показываем топ-5.** Если данных < 3 матчей — секция скрыта.

## Секция 5 — "МАТЧ ТУРА"

**Что:** по одной карточке на каждый завершённый тур (Тур 1 / Тур 2 / Тур 3).

**Алгоритм выбора "матча тура":**
- Берём все FINISHED матчи тура
- Для каждого считаем `spread` = (max points среди участников) − (min points среди участников)
- Выбираем матч с максимальным `spread` — тот, где ставки разошлись сильнее всего

**Карточка:**
```
┌────────────────────────────────────────────────┐
│  ТУР 1 · МАТЧ ТУРА                            │
│                                                │
│  🇧🇷 Бразилия  3 : 1  🇦🇷 Аргентина           │
│                                                │
│  9 из 14 угадали исход  ·  2 попали в счёт    │
│  ████████████████████░░░░░  64%               │
│                                                │
│  Сорвали куш: Иванов, Козлов                  │
│  Промахнулись: Петров (+4 ещё)                │
└────────────────────────────────────────────────┘
```

- "Сорвали куш" = участники с максимальным `points` в этом матче
- "Промахнулись" = `points === 0`, показываем первых 2 имени + "ещё N"

## Edge cases

- **Нет завершённых матчей:** показываем заглушку "Турнир ещё не начался — аналитика появится после первых матчей."
- **Менее 5 матчей:** дельта-карточки считают по всем доступным (не строго 5)
- **Участник без прогнозов на матч:** пропускаем при подсчёте серии, не засчитываем в "против большинства"
- **Все участники набрали 0 по матчу:** "матч тура" по нему не выбирается (spread=0)
