## Key Decisions Made

- **`revalidate = 60` на `/api/live-scores`** — все клиенты получают одинаковый кэшированный ответ, один запрос к football-data.org в минуту, не превышаем лимит (10 req/min)
- **Клиент-компонент `MatchesList`** — server component сериализует `Date → ISO string` и `externalId` для мэппинга на live API; client component делает polling и мержит данные
- **Prediction при live матче** — показываем отдельным блоком справа («мой прогноз x:x»), а не через `📝` эмодзи как для scheduled
