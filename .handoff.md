## Key Decisions Made
- **Next.js App Router** вместо Pages Router: современнее, server actions
- **next-auth@beta (v5)** — настройка: `lib/auth.ts` экспортирует `{ handlers, auth, signIn, signOut }`; route: `app/api/auth/[...nextauth]/route.ts` только экспортирует handlers
- **Vitest** вместо Jest — проще конфиг для unit-тестов pure functions
- **Прогноз неизменяемый**: DB `@@unique([userId, matchId])` + API 409 + SCHEDULED-gate
- **Чужие прогнозы скрыты** до `match.status === "FINISHED"` (в /api/grid)
- **Правила очков**: группа=11/10-N/0, плей-офф=22/(10-N+10)/10/0, финал=32/(15-N+15)/15/0
- **CRON_SECRET** защищает `/api/cron/sync-scores`
- **Субагент-ориентированная разработка**: один субагент на задачу, spec review + quality review после каждой
- **`PrismaStage`/`MatchStatus`** импортируются из `@prisma/client` в cron route; `Stage` из `@/lib/scoring` — разные типы, не смешивать
