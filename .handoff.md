## Key Decisions Made
- **Одна длинная страница** (не вкладки): всё сверху вниз — проще и работает на мобильном
- **Карточка прогноза тип Б**: название матча сверху, ниже разделитель → «Мой прогноз: X:X» / «Итог матча: X:X» на отдельных строках
- **Аналитика 2×2**: 100% попадания, динамика, сравнение с группой, двойник
- **profile-stats.ts**: все вычисления вынесены в отдельный файл с тестами (не в page.tsx)
- **CrossPrediction экспортируется**: нужен для типизации на стороне вызывающего кода
- **calcPointsByStage**: `p.points == null` (не `!p.points`) — чтобы не пропускать 0-очковые прогнозы
