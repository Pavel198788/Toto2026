## Согласованный дизайн таблицы бонусных прогнозов

**Расположение:** в конце страницы `/bonus`, показывается только когда `locked === true` (после 11 июня)

**Структура таблицы (горизонтальная):**

| Участник | 🏅 Полуфиналисты (+8) | 🥈 Финалисты (+15) | 🏆 Чемпион (+30) | Очки |
|---|---|---|---|---|
| Паша | 🇧🇷 🇦🇷 🇫🇷 🇩🇪 | 🇧🇷 🇦🇷 | 🇧🇷 Brazil | +46 |
| Аня | 🇪🇸 🇫🇷 🇵🇹 🇳🇱 | 🇪🇸 🇫🇷 | 🇪🇸 Spain | — |
| Миша (не заполнил) | не заполнил | — | — | — |

**Правила:**
- Флаги команд через `teamFlag()` из `lib/flags.ts`
- Участник без прогноза: строка полупрозрачная, в колонке полуфиналистов — «не заполнил»
- Колонка «Очки»: сумма `bonusPrediction.points` для пользователя; `—` если все points = null (результаты ещё не начислены); `+N` если есть начисленные очки
- Заголовки: «(+8)», «(+15)», «(+30)» — без слова «каждый»
- На мобильном таблица прокручивается горизонтально (`overflow-x: auto`)
- Подпись под таблицей: «Очки начисляются по мере прохождения этапов. — — результат ещё не известен.»

**Данные для таблицы:**
- Новый endpoint `GET /api/bonus/all`: возвращает список всех не-admin пользователей с их `bonusPredictions` (+ `locked` флаг)
- Если `!locked` — endpoint возвращает 403 (данные скрыты до начала ЧМ)
- Модель `BonusPrediction`: `{ userId, type: SEMIFINAL|FINALIST|CHAMPION, team, points }`

## Key Decisions Made
- **Таблица, не карточки**: пользователь выбрал горизонтальную таблицу для компактности

- **Очки суммируются**: колонка «Очки» = сумма всех начисленных бонусных очков, «—» пока ничего не начислено
