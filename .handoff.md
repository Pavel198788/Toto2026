## Key Decisions Made
- **Next.js App Router** вместо Pages Router: современнее, server actions убирают boilerplate
- **football-data.org** для данных матчей: бесплатный, поддерживает ЧМ, надёжный
- **Прогноз неизменяемый**: бизнес-правило, защита на уровне БД (`@@unique`) и API (409 на повтор)
- **Чужие прогнозы скрыты до конца матча**: предотвращает копирование, API не возвращает до `FINISHED`
- **Vercel Cron каждые 2 мин в дни матчей**: бесплатно, достаточно для актуальности
- **Правила очков** взяты из документа Евро 2024: группа=11/10-N/0, плей-офф=22, финал=32, премии=8/15/30
