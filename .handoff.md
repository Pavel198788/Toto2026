## Key Decisions Made
- **`await params` в Next.js 15+**: `app/matches/[id]/page.tsx` использует `{ params: Promise<{ id: string }> }` + `const { id } = await params` — обязательно для Next.js 15/16
- **Dialog из @base-ui/react**: в проекте используется `@base-ui/react`, не Radix. `onOpenChange={(open) => setShowConfirm(open)}` — совместимый синтаксис
- **Grid security**: фильтрация прогнозов на сервере (`match.status === "FINISHED" || p.userId === userId`) — чужие прогнозы не доходят до клиента
- **Leaderboard exactCount**: magic numbers 11/22/32 из `lib/scoring.ts` — точный счёт/победитель/плейофф
- **Все изменения на main**: проект без feature branches
